# Council of AIs

A task-oriented multi-model AI routing and budget-control engine.

## Quick Start

1. Install dependencies:
   ```bash
   pip install -e .
   ```
2. Copy `.env.example` to `.env` and fill in your keys:
   ```bash
   cp .env.example .env
   ```
3. Run the CLI:
   ```bash
   python -m council.app
   ```
